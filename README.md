# Grow plugin marketplace

The Claude plugin for [Grow](https://grow.nimbusit.us): routines, SMART goals and mentors through the Grow connector.

## Install

- **Claude Code:** `/plugin marketplace add manjime83/grow-plugin`, then `/plugin install grow@grow`.
- **claude.ai:** add the marketplace `manjime83/grow-plugin`, then install Grow.

## Don't edit this repository

Everything except this README is generated from `skills/` in Grow's source repository and pushed by its CI.
Each commit here is a new plugin version.
